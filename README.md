# 包材树脂智能选材平台 (Packaging Resin Selector)

单文件离线 HTML 工具，面向日化/化妆品包材开发的树脂选材决策。

**在线地址：https://jynjynjyn2023.github.io/packaging-resin-selector/**

## 功能模块（8 个标签页）

| 标签 | 内容 |
|---|---|
| 材料库 | 12 种常用包装树脂卡片（PS/GPPS、AS/SAN、MS/SMMA、PMMA、PET、PETG、PCTA、PCTG、PP、HDPE、LDPE、PC 等） |
| 参数对比 | 多选树脂物性并排对比，最优/最劣高亮 |
| 耐化学矩阵 | 13 类内容物体系（酯类/醇类/高醇/酮类/油类等）× 树脂耐化学评级 |
| 选材推荐 | 按内容物体系 + 重量/体积/工艺给出推荐排序与理由 |
| 成本测算 | 参考价区间 × 用量估算 |
| 必检项 | 按材料归口的包材测评必检项清单与典型失效模式 |
| 雷达画像 | 六维（耐化学/抗冲击/耐热/阻隔/成本优势/刚性）固定刻度雷达图，跟随内容物体系联动 |
| 数据溯源 | 数据来源编号、核对状态、冲突登记与变更记录 |

## 数据版本

- 数据 v1.1（2026-11-03 核对）· 界面 v1.3
- 评级口径详见配套《包材树脂耐化学评级口径说明.docx》

## 使用

下载 `index.html` 双击即可离线使用，无需安装任何依赖；也可直接访问上方在线地址。
